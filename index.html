💰 ExmeTrack – Sistema de Gestión de Gastos Personales

ExmeTrack es una aplicación web y móvil desarrollada para gestionar y controlar las finanzas personales. El sistema permite registrar gastos, organizar categorías, establecer presupuestos y consultar estadísticas para conocer la evolución de los gastos.

La aplicación está desarrollada siguiendo una arquitectura cliente-servidor, separando el frontend del backend. El backend proporciona una API REST encargada de gestionar usuarios, gastos, categorías y presupuestos.

La aplicación incorpora autenticación mediante JWT, protección de contraseñas mediante hashing, validación de datos y configuración CORS para controlar la comunicación entre frontend y backend.

La interfaz fue desarrollada con React y TypeScript, utilizando Ionic React para proporcionar una experiencia adaptable tanto a entornos web como móviles.

🛠️ Tecnologías

Python · FastAPI · React · TypeScript · Ionic React · MySQL · Azure · SQLAlchemy · JWT · Pydantic · Axios · Vite

🏆 TK3 – KO Tournament Manager

TK3 es una plataforma web desarrollada para gestionar torneos de eliminación directa (Knock-Out). El sistema permite registrar jugadores, crear torneos, generar automáticamente los cuadros de enfrentamientos y gestionar el avance de los participantes durante las diferentes rondas.

El proyecto utiliza una arquitectura cliente-servidor. Angular se encarga de la interfaz y la interacción con el usuario, mientras que FastAPI implementa la lógica de negocio y expone la API REST.

Una de las partes principales del proyecto es el algoritmo encargado de generar los brackets. Cuando el número de jugadores no corresponde con una potencia de dos, el sistema utiliza BYE para permitir que determinados jugadores avancen automáticamente.

El sistema también mantiene los jugadores inactivos mediante eliminación lógica, evitando perder su historial de torneos y estadísticas.

Además, incluye un dashboard de estadísticas donde se muestran resultados, torneos disputados, victorias, derrotas e historial reciente de combates.

🛠️ Tecnologías

Angular 19 · TypeScript · Python · FastAPI · SQLAlchemy · MariaDB · RxJS · API REST

Proyecto desarrollado siguiendo una estructura organizada por componentes, servicios, modelos, routers y capas de lógica de negocio.

✈️ Sistema de Gestión y Reservas de Vuelos

Aplicación desarrollada en Java para la gestión integral de una compañía aérea. El sistema permite administrar aeropuertos, aerolíneas, aviones, horarios, pasajeros, reservas y empleados.

El proyecto está orientado a trabajar con grandes volúmenes de información y presta especial atención a la protección de datos sensibles de los usuarios y a la seguridad de las operaciones.

La aplicación está estructurada por capas y utiliza Hibernate como ORM para gestionar la persistencia de datos relacionales, incluyendo sesiones, transacciones y consultas mediante HQL.

Además de la base de datos relacional, se utiliza MongoDB para almacenar información relacionada con los registros meteorológicos asociados a los aeropuertos.

🔐 Seguridad aplicada

El proyecto incorpora conocimientos de programación segura y protección de información sensible. Se trabajaron técnicas de cifrado y descifrado, control de acceso según el tipo de usuario y mecanismos destinados a proteger la información almacenada.

También se implementó la firma digital de las reservas mediante el algoritmo DSA, permitiendo comprobar la integridad de la información asociada a cada reserva.

Para la protección de contraseñas y datos sensibles se estudiaron y aplicaron mecanismos criptográficos como MD5 y DES dentro del contexto académico del proyecto.

También se incorporaron controles de permisos para diferenciar las operaciones disponibles para administradores y empleados, evitando accesos no autorizados a determinadas funcionalidades.

🛠️ Tecnologías

Java · Hibernate · HQL · MySQL · MongoDB · ORM · Criptografía · DSA · DES · MD5 · Programación segura

🤖 Automatización con n8n, Gemini y Discord

Proyecto académico de automatización desarrollado con n8n, integrando inteligencia artificial mediante Gemini y comunicación mediante Discord.

El workflow recibe un mensaje mediante un Chat Trigger y lo utiliza como entrada para Gemini. La respuesta generada posteriormente pasa por un nodo Code desarrollado en JavaScript encargado de limpiar el contenido, eliminar saltos de línea y formatos Markdown y limitar el mensaje para adaptarlo a Discord.

Después se utiliza un nodo Switch para analizar el contenido del mensaje y detectar palabras clave como general, bienvenida o nota.

Dependiendo de la palabra detectada, el workflow dirige automáticamente el mensaje hacia un canal diferente de Discord.

Este proyecto me permitió trabajar de forma práctica con automatización de procesos, workflows, JavaScript, inteligencia artificial, APIs e integración entre diferentes plataformas.

🛠️ Tecnologías

n8n · Gemini · JavaScript · Discord · APIs · Automatización
