✈️ Sistema de Gestión de Reservas de Vuelos

Aplicación desarrollada en Java para gestionar una plataforma de reservas aéreas, incluyendo aeropuertos, aerolíneas, aviones, vuelos, horarios, pasajeros, empleados y reservas.

El proyecto está orientado a trabajar con grandes volúmenes de información y datos sensibles, por lo que incorpora diferentes técnicas de programación segura.

Se implementaron mecanismos de cifrado y protección de información sensible, control de acceso según el tipo de usuario y medidas para evitar que determinados usuarios pudieran acceder a información que no les correspondía.

La persistencia relacional se realizó mediante Hibernate y ORM, utilizando sesiones, transacciones y consultas HQL.

Además, se utilizó MongoDB para almacenar los registros meteorológicos asociados a los aeropuertos, combinando una base de datos relacional con una base de datos NoSQL.

El proyecto también incluyó conceptos de seguridad como hashing de contraseñas, cifrado de información sensible y firma digital de reservas para garantizar la integridad de los datos.

Tecnologías:

Java · Hibernate · ORM · HQL · MySQL · MongoDB · Seguridad · Cifrado · Firmas digitales · DSA

🤖 Automatización con n8n + Gemini + Discord

Workflow de automatización desarrollado con n8n para integrar inteligencia artificial mediante Gemini con Discord.

El flujo recibe un mensaje mediante un Chat Trigger, lo envía a Gemini para generar o procesar la respuesta y posteriormente utiliza JavaScript para limpiar el contenido.

Después, un nodo Switch analiza palabras clave dentro del mensaje y decide automáticamente a qué canal de Discord debe enviarse la información.

Este proyecto me permitió trabajar con automatización de procesos, APIs, expresiones de n8n, JavaScript, inteligencia artificial y comunicación entre servicios.

Tecnologías:

n8n · Gemini · JavaScript · Discord · APIs · Automatización
